# 用量统计托盘

常驻 Windows 托盘的小面板：**不用开浏览器**，随时看到已登录账号在不在线、余额与订阅还剩多少，
并直接取用账号的 API Key。

**当前版本：v0.4.0**

![面板](docs/panel-preview.png)

## 快速开始

* **下载**：从 [Releases](https://github.com/Kylineyes/sub2api_tray/releases) 取
  `sub2api_tray-v*-windows-x64.zip`，解压后双击 `sub2api_tray.exe`。
* **从源码**：需要 Rust 1.95+ 与 MSVC 工具链，`cargo run` 即可（启动后面板默认隐藏，点托盘图标打开）。

首次运行会在 exe 同目录生成配置文件与账号文件；整个程序是绿色的，删掉目录即卸载。

## 能做什么

* **账号**：点面板顶部总览卡片里的 **＋ 登录**，填地址、账号、密码即可登录（支持两步验证），
  最多同时 10 个账号；点账号标题行展开/收起明细，**右侧「退出」**可移除账号（带二次确认）。
* **状态**：后台按设定间隔刷新在线状态、余额与订阅用量；多个账号会有界并行刷新（最多 4 个），
  托盘图标右下角的小圆点用 **绿 / 黄 / 红** 表示"全部在线 / 有账号离线 / 有账号凭据失效"，
  也能随时「立即刷新」。
* **API Key**：展开账号即看到全部 Key（名称、打码值、已用/总额度、限速用量、所属分组）。
  鼠标悬浮到某个 Key 时才显示「复制」「调额度」「删除」操作；多个展开账号的 Key 列表会并行拉取；
  只有点「复制」按钮会把完整值写入剪贴板，避免误点标题覆盖剪贴板。展开账号后，
  「新增key」位于标题行右侧、登出账户按钮上方：填写名称、选择分组和可选额度后创建，
  新 Key 会一次性展示并自动复制。
  调额度可把 0 设为不限额并同时清零已用额度；删除前会二次确认，且不可恢复。
  只在 Key 配置了 5 小时 / 1 天 / 7 天限速窗口时展示对应窗口的限速用量；三个窗口都未配置时不展示限速统计描述。
  断网时回退展示上次缓存的列表。
* **我的用量曲线**：展开账号后可按 **24 小时 / 7 天 / 30 天** 查看当前登录账号自己的历史 token 用量趋势
  （原生绘制）；服务端稀疏时间桶会按真实小时/日期补零，横轴标注起止时间。支持「全部 Key」与单个
  API Key 切换、用量区独立展开/收起，并可在总 Token / 输入 / 输出 / 命中率之间切换曲线；下方汇总
  输入、输出、Cache 写读、命中率、请求数与实际花费。普通 user 账号与管理员一样走自己的用户态接口。
* **双主题**：按 Sub2API 的 Teal/Cyan 品牌色提供日间/夜间两套配色；标题栏日月按钮可一键切换，设置页也可修改并持久化。
* **设置**：标题栏齿轮里改账号名打码、主题、刷新间隔、请求超时，开关开机自启、检查新版本。
* **记住状态**：哪个账号是展开的会记在配置里，重启应用或重启电脑后仍是展开的样子。
* **可拖动 / 可缩放**：按住标题左侧六点抓手或标题文字即可移动面板；四角与四边都可以拖动缩放，
  最小 320×240。界面按逻辑点渲染，高分辨率屏与 125%/150% 系统缩放下字体会等比放大，不会变小。
* **置顶显示**：点右上角**图钉**把面板钉住，之后点别的窗口面板也不会收起；再点一次取消（状态会记住）。
* **单实例**：重复启动会被拒绝并提示"已有一个实例在运行"，避免两个副本互相覆盖账号文件。
* **轻量**：Release 版单文件约 7.6 MB，便携 zip 约 3 MB，不依赖 .NET / WebView2 / 运行时。

## 托盘操作

| 操作 | 效果 |
| --- | --- |
| 左键单击托盘图标 | 显示 / 收起面板 |
| 右键单击托盘图标 | 菜单：立即刷新 / 版本 / 退出 |
| 面板内 | 登录、查看状态、展开 Key、复制 Key、退出账号、设置 |
| 标题左侧抓手或标题文字 | 拖动面板位置 |
| 面板四角 / 四边 | 拖动缩放 |
| 标题栏日月按钮 | 切换日间 / 夜间主题 |
| 面板标题栏 | 主题、图钉（置顶/取消置顶）、齿轮（设置） |
| `Esc` | 关闭最上层弹窗；没有弹窗时收起面板 |

## 最近更新

* **v0.4.0**：新增单 Key 调额度、删除与悬浮操作按钮；用量汇总改为固定宽度流式布局；
  多账号状态与 Key 列表有界并行拉取；设置页打开不再同步等待开机自启查询；
  设置页切换主题立即预览，取消时回滚；
* **v0.3.0**：新增 Sub2API 日间 / 夜间双主题，支持标题栏切换并持久化；
* **v0.3.0**：用量曲线支持 24 小时 / 7 天 / 30 天、全部 Key / 单 API Key、输入 / 输出 / 命中率切换；
* **v0.3.0**：面板支持标题栏拖动，四角与四边均可缩放；用量区可独立展开 / 收起；
* 用量曲线按真实时间轴补零，但只绘制有数据的节点，空白时段不显示零值点；
* 登录入口并入顶部总览卡片，「退出账号」移到账号标题行右侧（保留二次确认）；
* 去掉冗余的 Key 弹窗——展开即见、点击即复制；
* 记住账号的展开状态，重启后保持；
* 设置页可开关开机自启、检查新版本；新增单实例保护。

## 构建

```powershell
cargo run                 # 调试运行
cargo build --release     # 产物：target\release\sub2api_tray.exe
```

macOS 代码路径已实现但**尚未实机验收**，暂不提供构建产物。

## 发布

在 `main` 上打 `v*` tag 即触发 GitHub Actions：跑格式检查、clippy 与单元测试，
编译 Windows x64 版本并自动挂到该 tag 的 Release。

```bash
git tag v0.4.0
git push origin v0.4.0
```
