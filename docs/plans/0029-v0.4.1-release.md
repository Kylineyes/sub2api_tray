# 0029 v0.4.1 发布：Key 日期选择与统一 UI 样式

| 字段 | 内容 |
| --- | --- |
| 编号 | 0029 |
| 分支 | `release/v0.4.1` |
| 状态 | 已完成 |
| 提出日期 | 2026-10-22 |

## 一、背景

v0.4.0 之后累计完成了账号原地重新登录、DPAPI 错误码日志、统一 UI 样式、新增 Key 日期选择器和多处布局修复。
需要将这些变更收敛为 v0.4.1 并推送到远端 `dev`。

## 二、范围

**包含：**

* 新增 Key 有效期支持按天数或日期选择器指定到时分；
* 凭据损坏账号支持原地重新登录，保留账号与 Key 缓存；
* DPAPI/钥匙串解密错误日志保留底层错误码；
* 新增 `src/ui_style.rs` 与 `docs/ui-style-guide.md`，统一颜色、字号、按钮、圆角、间距和表单控件；
* 修复危险按钮对比度、账号标题按钮居中、日期/时间对齐、分组字号、额度输入间距；
* 版本升级到 0.4.1，README/AGENTS 同步更新。

**不包含：**

* 不创建 git tag；
* 不自动合并到 `main`；
* 不改变后端接口协议。

## 三、验收标准

1. `cargo fmt --check` 通过；
2. `cargo clippy --all-targets -- -D warnings` 通过；
3. `cargo test` 通过；
4. `cargo build --release` 通过；
5. `Cargo.toml`、`Cargo.lock`、README 的版本一致为 `0.4.1`；
6. 推送到 `origin/dev`，不操作 `main`。

## 四、结果

* 完成日期：2026-10-22
* 实际验证：`cargo test` 124 passed、8 ignored；clippy 与 release build 通过。
* 偏差：日期选择器使用 `egui_extras::DatePickerButton` 的年/月/日下拉模式，不展示日历星期网格。
