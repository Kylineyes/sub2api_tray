## 一、背景

托盘已经支持查看、复制、调额度和删除单个账号下的 API Key，但创建仍需打开 Web 后台。
Sub2API 已提供 `POST /api/v1/keys` 与 `GET /api/v1/groups/available`，托盘可以补齐创建能力。

## 二、目标

在账号展开后的 Key 列表顶部提供「添加 API Key」，填写名称、分组与额度后直接创建。

## 三、范围

**包含：**

* 展开账号标题行最右侧、登出账户按钮上方增加文字居中的「新增key」按钮；
* 弹窗异步加载当前账号可绑定分组；
* 支持填写名称、选择分组、设置额度（0 表示不限额）；
* 创建成功后将完整 Key 一次性展示并自动复制到剪贴板；
* 新 Key 摘要写回面板缓存与 `accounts.json`；
* 错误时保留弹窗并展示原因。

**不包含：**

* 不支持自定义 Key 值；
* 不支持 IP 白名单、过期时间和限速窗口设置；
* 不把完整 Key 写入本地缓存或日志。

## 五、验收标准

1. 操作：展开账号 → 预期：两个按钮贴整行最右侧，文字在按钮内居中，「新增key」在「登出账户」上方。
2. 操作：点击按钮 → 预期：弹窗出现并异步加载分组。
3. 操作：填写名称、选择分组、输入额度并创建 → 预期：成功弹窗展示完整 Key，且已复制到剪贴板。
4. 操作：关闭结果弹窗 → 预期：新 Key 出现在列表中，完整值只存在于本次弹窗期间。
5. 操作：分组加载或创建失败 → 预期：弹窗保留并展示可读错误。

## 七、风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 完整 Key 泄漏到缓存 | 安全风险 | 只有弹窗状态保存完整值，关闭即丢弃 |
| 分组权限变化 | 创建失败 | 展示服务端错误，保留表单 |
| 并发创建重复提交 | 多个 Key | 提交期间禁用按钮，且同一时间只允许一个请求 |

回滚方式：移除添加入口与创建相关状态，不影响查看/删除/调额度。
