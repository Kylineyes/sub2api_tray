## 一、背景

用量曲线每 60 秒刷新时，`usage_loading=true` 会让整个图表被 spinner 替换，
数据返回后再重新绘制，造成短暂消失再出现。

## 二、目标

后台刷新时保留已有曲线，只在首次加载或切换到一个没有缓存的区间/Key 时显示 spinner。

## 三、范围

包含：已有数据时刷新只显示更新中指示；失败时保留上次成功曲线；缓存为空时仍显示加载占位。
不包含：不改变请求频率和缓存策略。

## 四、完成点

* [x] 有缓存时刷新不隐藏图表
* [x] 标题行显示更新中指示
* [x] 失败时保留旧曲线
* [x] 单测与实机验证

## 五、验收标准

1. 曲线有数据时触发后台刷新 -> 曲线不消失，只出现更新中指示。
2. 刷新成功 -> 数据平滑更新为最新结果。
3. 刷新失败 -> 旧曲线保留并显示错误提示。
4. 首次加载或切换无缓存区间 -> 正常显示加载占位。
