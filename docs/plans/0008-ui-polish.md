## 一、背景

0007 的悬浮高亮是"半透明白底叠在文字上"，导致高亮后文字反而看不清；
而且是瞬时出现，鼠标划过会闪。需求方另外要求：底栏的退出与提示都删掉、退出只留在右键菜单；
"最近 1 小时用量"不再追求（保持近 5 小时口径）。

## 二、范围

* 悬浮改为**背景色插值**（CARD_BG → 更亮的深蓝）并同步**提亮文字**，不再叠加半透明层；
* 约 90ms 的指数式淡入淡出（`stable_dt` 驱动，逐帧排重绘），接近系统菜单的高亮过渡；
* 底栏只保留操作反馈（如"已复制"），删除"退出"按钮与快捷键提示；退出只走托盘右键菜单；
* 达到 10 个账号时禁用"＋ 登陆新用户"按钮并给出悬浮说明；
* "最近用量"统一为**近 5 小时**口径，不再提 1 小时。

## 三、验收标准

1. 鼠标移到账号卡片 → 预期：底色与文字颜色约 0.1s 内平滑过渡，文字仍清晰；
   移开同样平滑淡出，无闪烁。
2. 鼠标移到展开的 Key 行、弹窗里的 Key 行 → 同上。
3. 面板底部 → 预期：没有"退出"按钮、没有快捷键提示；有操作时只显示"✓ …"反馈。
4. 已登录 10 个账号 → 预期：顶部按钮变灰、不可点击，悬浮提示已达上限。
5. `cargo test` → 全部通过。

## 四、结果

* 验证：`cargo fmt --check` / `clippy -D warnings` / `cargo test`（89 passed）/ `build` 全绿；
* 视觉与手感（过渡曲线、文字对比度）需人工确认；过渡时长可调 `HoverState::t` 里的 0.09 常数。
