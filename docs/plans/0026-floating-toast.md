# 0026 底部操作提示改为半透明浮层

| 字段 | 内容 |
| --- | --- |
| 编号 | 0026 |
| 分支 | `feat/api-key-quota-adjust` |
| 状态 | 已完成 |
| 提出日期 | 2026-10-22 |

## 一、背景

底部页脚原先只为显示操作反馈（如「已复制」「额度已更新」）保留一条布局区域。
没有提示时它仍然压缩滚动内容高度；提示出现时又会推动布局，视觉上也与托盘气泡不够统一。

## 二、目标

删除固定底栏，把操作反馈改成贴在面板底部上方的半透明浮层。

## 三、范围

**包含：**

* 移除 `panel_footer` 固定布局；
* 新增底部居中的半透明 Toast；
* Toast 使用前景层绘制，不参与滚动区布局；
* 额度更新、删除、复制等现有反馈继续复用同一提示通道。

**不包含：**

* 不改变 `toast` 的文本内容与过期时间；
* 不新增通知中心；
* 不新增依赖。

## 四、完成点

* [x] 移除底部 `Panel`；
* [x] 新增 `draw_toast_overlay`；
* [x] 半透明背景 + 强调色描边；
* [x] 提示出现/消失不再推挤账号卡片。

## 五、验收标准

1. 操作：没有提示时打开面板 → 预期：底部不再有空白页脚占位。
2. 操作：完成调额度/复制/删除 → 预期：面板底部上方出现圆角半透明提示条。
3. 操作：提示出现或消失 → 预期：账号卡片和滚动区域不发生上下跳动。

## 六、测试方式

* `cargo fmt --check`
* `cargo clippy --all-targets -- -D warnings`
* `cargo test`
* `cargo build --release`

## 七、风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 浮层遮挡底部内容 | 少量内容被临时覆盖 | 4 秒后自动消失，且宽度限制在面板内 |

回滚方式：恢复 `panel_footer` 与 `draw_footer`。
