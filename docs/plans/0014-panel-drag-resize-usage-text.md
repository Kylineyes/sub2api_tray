## 一、背景

用量区字号偏小，曲线和时间标签在托盘面板里不够易读。面板目前只能通过右下角自绘手柄缩放，
标题栏也无法拖动；用户需要把面板移到顺手的位置，并从任意角落调整大小。

## 二、目标

用量区文字与曲线整体放大一档，面板可用标题栏拖动，并支持四角及四边缩放。

## 三、范围

包含：

* 用量区标题、按钮、指标、横轴与悬浮提示字号统一放大一档；
* 用量曲线绘图区高度增加；
* 标题栏增加拖动抓手，标题文字也可拖动窗口；
* 四角加四边缩放热区，使用系统 BeginResize；
* 四角绘制缩放提示线，并显示对应鼠标指针。

不包含：

* 不保存窗口位置与尺寸到配置文件；
* 不改变托盘图标本身的位置（系统托盘图标位置由操作系统管理）；
* 不引入第三方窗口装饰库。

## 五、验收标准

1. 展开用量区 -> 字体、指标和横轴明显比之前大一档，曲线绘图区更高。
2. 按住标题左侧拖动抓手或标题文字 -> 面板跟随鼠标移动。
3. 从左上、右上、左下、右下任意角落拖动 -> 对应方向缩放。
4. 从上、下、左、右边缘拖动 -> 对应方向缩放。
5. 缩放后仍遵守 320x240 最小尺寸，内容可滚动。

## 七、风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 拖动热区与标题按钮冲突 | 按钮点不到 | 只让抓手和标题文字拖动，按钮保持独立 |
| 边缘热区挡住内容 | 点击边缘误触缩放 | 热区限制在窗口边缘约 8px，四角 18px |
| 系统不响应 BeginResize | 无法缩放 | Windows 实机验证；失败时保留右下角手动缩放兜底 |

回滚方式：git revert 合并提交。
