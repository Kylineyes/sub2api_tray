# 0037 v0.5.0 发布

| 字段 | 内容 |
| --- | --- |

| 状态 | 已完成 |

## 一、目标

将 v0.4.3 后累计完成的桌面悬浮球能力收敛为 v0.5.0，并用固定演示账号刷新 README 截图。

## 二、版本内容

* 桌面悬浮球：托盘菜单/主面板选择主账号或主 Key、置顶常驻、拖拽、四边停靠收起；
* 悬浮球小/中/大三档尺寸；
* 数据变化时的气泡上浮淡出动画；
* DeepSeek 奖励/充值余额展示；
* 金额千分位格式；
* 标题栏整段拖动热区；
* 托盘主 Key 菜单二级缩进。

## 三、发布操作

* `Cargo.toml` / `Cargo.lock` 版本升至 `0.5.0`；
* README 当前版本、最近更新与 tag 示例更新为 v0.5.0；
* 使用 `testdata/demo` 固定演示账号重新生成：
  - `docs/panel-preview.png`
  - `docs/panel-collapsed.png`
* 推送 `origin/release/v0.5.0` 与 `origin/dev`。

## 四、验证

* `cargo fmt`
* `cargo clippy --all-targets -- -D warnings`
* `cargo test`：134 passed，8 ignored
* `cargo build --release`

## 五、结果

* 完成日期：2026-10-23
* 版本：v0.5.0
