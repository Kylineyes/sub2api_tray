# 0024 v0.4.0 版本与设置页启动优化

| 字段 | 内容 |

## 一、背景

本次迭代已经包含单 Key 调额度、删除、悬浮操作、固定宽度用量汇总、多账号并行拉取等改动，
需要把版本升级到 v0.4.0。

设置页点击后偶尔需要等待较久才出现。排查发现打开设置时会同步执行
`autostart::is_enabled()`，Windows 下该函数会启动 `reg query` 子进程并等待结果；
机器上注册表代理或安全软件变慢时，整个 egui UI 线程会被阻塞。

## 二、目标

发布 v0.4.0，并让设置页立即打开，开机自启状态改为后台异步读取。

## 三、范围

**包含：**

* `Cargo.toml` / `Cargo.lock` / README 版本升级到 0.4.0；
* 启动后在后台读取开机自启状态；
* 打开设置页时只读内存缓存，不阻塞 UI；
* 状态未知时显示读取中，并暂时禁用保存；
* 保存时使用缓存状态，避免再次同步查询；
* 设置页选择日间/夜间主题时立即预览，无需关闭窗口；
* 检查到新版本时显示「点击进入下载最新版本」超链接，并展示 Release URL。

**不包含：**

* 不改变更新检查逻辑；
* 不自动下载或自动安装新版本；
* 不新增依赖。

## 四、完成点

## 五、验收标准

1. 操作：点击标题栏齿轮 → 预期：设置弹窗立即出现，不等待注册表查询。
2. 操作：设置页刚打开且自启状态尚未返回 → 预期：显示读取中，保存按钮不可用。
3. 操作：自启状态返回后 → 预期：复选框显示真实状态，保存按钮恢复。
4. 操作：设置页切换日间/夜间 → 预期：面板与弹窗立即换色，不需要关闭窗口；取消后恢复原主题。
5. 操作：检查到新版本 → 预期：显示「点击进入下载最新版本」超链接及 Release URL；
   点击后由系统默认浏览器打开，不在托盘内嵌网页，也不自动下载安装。

## 七、风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 自启状态读取失败 | 设置页一直显示读取中 | 重新打开设置页会再次发起读取 |
| 用户过早保存 | 自启状态被误写 | 状态未知时禁用保存按钮 |

回滚方式：回退本功能对应提交。
