# 0020 恢复标题栏按钮右对齐

## 一、背景

新增双主题时标题栏控件被改成从左到右排列，版本号、主题、图钉和设置按钮都挤在标题后面，
与旧版本右侧工具组不一致。

## 二、目标

恢复旧版标题左对齐、工具组右对齐的布局，并把主题按钮并入右侧工具组。

## 三、范围

包含：标题和拖动抓手靠左；版本号、图钉、主题、设置靠右。
不包含：不改变按钮功能和主题逻辑。

## 四、完成点

* [x] 恢复旧版 with_layout 右对齐实现
* [x] 主题按钮加入右侧按钮组
* [x] 构建与截图验证

## 五、验收标准

1. 标题和拖动抓手固定在左侧。
2. 版本号、图钉、主题、设置按钮整体贴右边缘。
3. 窗口缩放时右侧按钮仍保持在右侧。
4. 各按钮点击功能正常。

## 六、测试方式

* cargo fmt --check
* cargo clippy --all-targets -- -D warnings
* cargo test --locked
* cargo build --release --locked
* Windows 实机截图

## 七、风险与回滚

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 窄窗口空间不足 | 控件拥挤 | 保持旧版紧凑尺寸，必要时后续再做响应式收纳 |

回滚方式：git revert 合并提交。
