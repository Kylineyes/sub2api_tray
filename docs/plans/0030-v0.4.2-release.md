# 0030 v0.4.2 发布：设置页重设计与异步保存

| 字段 | 内容 |
| --- | --- |
| 编号 | 0030 |
| 分支 | `release/v0.4.2` |
| 状态 | 已完成 |
| 提出日期 | 2026-10-22 |

## 一、背景

v0.4.1 后设置页仍使用旧的垂直布局；保存设置时会在 UI 线程同步写 `app.json` 和注册表，
用户会感到一段时间无响应。Key 列表还会为未显示的悬浮按钮保留高度，列表不够紧凑。

## 二、范围

**包含：**

* 设置页按统一 UI 规范重设计：标题区、分组卡片、统一标签/输入/按钮；
* 设置保存改为后台线程，期间显示「正在保存设置」阻塞式进度弹窗；
* 保存期间禁止 Esc 关闭和重复提交；
* Key 操作按钮未悬浮时不保留占位行高度；
* 版本升级到 0.4.2，README/AGENTS 同步更新。

**不包含：**

* 不创建 git tag；
* 不推送 `main`；
* 不改变 `app.json` / `accounts.json` schema。

## 三、兼容性

v0.4.2 未修改配置文件 schema，旧版 `app.json` 与 `accounts.json` 应可直接读取。
DPAPI 凭据仍绑定当前 Windows 用户与机器，跨用户/跨机器复制后仍需重新登录。

## 四、验收

* `cargo fmt --check`
* `cargo clippy --all-targets -- -D warnings`
* `cargo test`：124 passed，8 ignored
* `cargo build --release`
* 推送 `origin/release/v0.4.2` 与 `origin/dev`

## 五、结果

* 完成日期：2026-10-22
* 旧版 v0.4.1 可执行文件保留为 `target/preserved/sub2api_tray-v0.4.1.exe`（仅本地，不入库）。
