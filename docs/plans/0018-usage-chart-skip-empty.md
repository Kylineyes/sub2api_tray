## 一、背景

用量趋势接口只返回有数据的桶，客户端为了真实时间轴补了零值桶。
当前绘图仍把这些零值桶作为折线节点，导致长时间贴着基线的直线，
悬浮时还会出现总 0、输入 0、请求 0 的无数据提示。

## 二、目标

曲线只展示有实际数值的时间点；无数据时间点不画线、不画点、不弹提示，
但横轴仍保留完整查询区间。

## 三、范围

包含：按当前指标过滤 value > 0 的时间桶；折线、面积、圆点和悬浮提示只使用过滤后的数据；
横轴起止时间仍使用完整时间范围；当前指标全无数据时显示占位文案；单测覆盖过滤与时间位置保留。

不包含：不改变服务端请求和汇总合计；不改变全部 Key / 单 Key 逻辑。

## 四、完成点

* [x] 指标采样过滤零值
* [x] 绘图使用保留原始索引的数据点
* [x] 悬浮只命中真实数据点
* [x] 空指标占位
* [x] 单测与实机验证

## 五、验收标准

1. 24 小时曲线中有空白时段 -> 空白时段不画 0 值折线和圆点。
2. 悬浮空白时段 -> 不出现全 0 时间点提示。
3. 横轴仍显示查询的完整起止日期。
4. 某指标全为 0 -> 显示该指标暂无数据，不崩溃。
5. 汇总数字不受影响。
